# Kochwelt

Rezeptseite rund ums Kochen – mit einem ausführlichen Rezept für frisch zubereitete Maultaschen.

## Inhalt

- Rezeptbeschreibung mit Zutaten und Zubereitung
- Gestaltung mit reinem HTML und CSS

## Technologien

HTML5 · CSS3

## Projekt starten

1. Repository klonen: `git clone https://github.com/KonstantinFenzlein/Kochwelt.git`
2. `index.html` im Browser öffnen.
